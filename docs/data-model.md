# 数据行为与适配边界

## 总表

19 个主要字段：序号、下单人/订单号、下单时间、需求时间、计划时间、完成时间、成品编码、成品名称、成品规格、需求数量、实际生产数量、报废数量、最新单据状态、进度条、毛坯编码、毛坯名称、毛坯规格、单个用量、采购状态。

人工字段保存于本工具 SQLite 库。名称、规格、BOM 与单据来源保留快照；查询失败显示原因并保留历史资料。不存在、未查询和实际为零分别处理。计划时间尚未实现；完成时间当前为生产报检时间。

## 生产与采购

生产阶段：生产加工单 → 材料出库单 → 报检单 → 检验单 → 产成品入库单，每个阶段 20%。按最新有效单据确定状态，不盲取历史最高阶段。

生产关联使用源单头和行主键，可指定批次。实际产量与报废数仅统计最终生产检验，检验项目重复行去重。导入资料采用订单号、成品编码、批次精确匹配；绑定源生产行后不混算导入生产资料。

采购阶段：采购申请单 → 采购订单 → 采购报检单 → 检验单 → 采购入库单。显示 BOM 子件最近采购状态，属于物料级，不代表订单专属、库存承诺或自动分配。多个子件保留各自状态。

## S7 适配

当前适配器依赖常规页面菜单及查询接口，包括存货档案、BOM 维护、生产加工单列表、材料出库、生产报检、检验和入库报表。字段映射在 `src/s7.js`，查询路径与条件也集中于此。

不同版本的菜单、报表权限和返回字段可能不同，必须先验证自己的部署。账号只通过本机服务传入源系统；保存账号使用 Windows DPAPI，业务备份不含账号。浏览器从本机 Chrome/Edge 启动，不读取个人浏览器配置。

## 导入与备份

导入会先整批校验：物料按编码更新；BOM 按成品替换本批完整子件；单据按业务链和源 ID 更新；订单按规范化行内容防重复。修改原订单应使用编辑，不应通过修改文件内容反复新增。

完整备份保存本工具资料和审计，恢复前备份现有库，再以事务替换。CSV 是查看用途，含采购范围、各子件状态、查询错误及来源，不是恢复文件。
